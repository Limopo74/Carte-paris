# Ma carte de Paris

Appli personnelle pour placer ses lieux préférés sur une carte de Paris et voir ceux qui sont près de soi, rangés par cercles.

- Ajouter un lieu à sa position ou avec une adresse.
- Appui long sur la carte pour ajouter un lieu à cet endroit.
- « Autour de moi » : cercles réglables (100 m au minimum), liste triée par distance avec un temps à pied estimé (détours compris), bouton « Y aller » vers Google Maps.
- Recherche dans mes lieux, favoris, catégories personnelles, déplacement d’N lieu avec un viseur.
- Les lieux restent sur le téléphone (rien n'est envoyé à un serveur). Export et import dans les réglages.

Carte © OpenStreetMap. Adresses : service de géocodage de l'IGN (Base Adresse Nationale).

Tests : `npm test`
